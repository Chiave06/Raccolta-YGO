        Altri dispositivi

        Collega un repository GitHub privato per ritrovare raccolta, lista dei desideri e foto su telefono e computer.

        Come si collega
        1. Su GitHub crea un repository privato solo per i tuoi dati, per esempio ygo-dati, con l'opzione “Add a README file”.
        2. Vai in Settings → Developer settings → Personal access tokens → Fine-grained tokens e crea un token. Come accesso scegli “Only select repositories” e solo ygo-dati. Nei permessi imposta Contents: Read and write.
        3. Incolla qui sotto nome del repository e token, poi premi “Collega e sincronizza”.
        4. Su ogni altro dispositivo apri questo sito e ripeti il passaggio 3 con gli stessi dati.

        Il token resta salvato solo in questo browser. Se due dispositivi cambiano la stessa carta, vince la modifica più recente.
